# Competition routing and rule verification

## Source priority

Use the first available authoritative source and retain its URL or file:

1. National organizer or ministry notice and attachments
2. Provincial organizer notice
3. University competition office or innovation center notice
4. User-provided official files
5. News reports or prior-year materials only as clearly labeled background

Rules, names, tracks, eligibility, quotas, deadlines, scoring, page limits, and templates can change every year. Never transfer a prior-year requirement into the current submission without verification.

## Context record

Capture these fields before rule-dependent work:

| Field | Required value |
|---|---|
| Competition | Official current name |
| Year and stage | School/provincial/national and round |
| Organizer | Issuing authority |
| Track/category | Exact official wording |
| Eligibility | Student status, team, project-age, IP rules |
| Deliverables | File type, template, length/size, naming |
| Evaluation | Rubric, weights, special gates |
| Timing | Submission and defense deadlines |
| Evidence | Official URLs/files and access date |

If any rule affects eligibility or submission acceptance and remains unknown, stop finalization and list it as a hard blocker.

## Typical positioning lenses

These are analysis lenses, not fixed official rubrics:

- **大创:** research/entrepreneurship training logic, feasible milestones, student ownership, learning and validation.
- **挑战杯:** problem significance, investigation or technical innovation, social value, evidence and implementation credibility.
- **中国国际大学生创新大赛:** innovation, team, commercialization or impact, growth evidence, track fit, and roadshow quality.
- **Other startup contests:** customer pain, differentiation, traction, unit economics, execution, risks, and investment logic.

Always replace these lenses with the verified current rubric when one exists.
