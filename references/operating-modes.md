# Operating modes

## Intake

Use when the competition, stage, track, or evidence base is incomplete. Inspect available material first, then produce:

- a filled context record with `verified`, `provisional`, or `unknown` per field;
- an inventory of existing artifacts and evidence;
- no more than the minimum blocking questions;
- a safe first-pass outline or audit that does not depend on unknown rules.

## Audit

Audit against official rules, evidence, internal consistency, and file behavior. Rank findings:

- **Critical:** eligibility, false claim, missing authorization, wrong template, deadline, anonymity, unreadable file, or other rejection risk;
- **Major:** high-weight rubric gap, contradictory metric, unsupported key claim, broken financial logic, or defense exposure;
- **Minor:** clarity, density, visual hierarchy, citation style, or low-impact polish.

Each finding should identify the affected artifact/location, evidence, consequence, and smallest safe fix.

## Strategy

Use the verified rubric rather than a generic startup framework. Produce a positioning statement, rubric matrix, key differentiators, credible proof plan, and prioritized backlog. Separate:

- work that improves the project itself;
- work that improves proof of the project;
- work that improves communication of existing proof.

## Build

Before drafting, select authoritative values from the competition brief and claim ledger. Build requested artifacts in editable form and export only when useful. After every material change, update dependent artifacts or record them as stale in the deliverable register.

## Defense

Create a timed narrative, slide-level speaker notes, demo path and fallback, role allocation, and evidence-backed Q&A. Rehearsal findings may reopen earlier gates; visual polish does not close them.

## Final QC

Treat the submission candidate as immutable during validation. If a change is necessary, create a new candidate, rerun affected checks, and update the manifest. Report the final state with concrete validation evidence rather than a general assurance.
